# Diseño (Lienzo)

Responsable: Lienzo (diseñador web y de marca). **Estado: carpetas vacías**; se llenan cuando empiece la primera pantalla.

| Subcarpeta | Qué va aquí |
|---|---|
| `prototypes/` | Prototipos HTML de las pantallas, aprobados por la supervisión antes de implementarlos. |
| `design-system.md` *(pendiente)* | Design system: paleta (con contraste AA verificado), tipografía, espaciados, radios, sombras, estados (hover, foco, error, deshabilitado) y componentes base. Se crea con el primer prototipo. |

Reglas que ya aplican:

- Marca: **Cuartico** es la herramienta interna; **Combazo** es la marca de cara al cliente (ver [README](../../README.md)).
- La web es bilingüe (es/en): los textos de interfaz se entregan en los dos idiomas.
- Usuarios en Cuba con datos móviles caros e inestables: diseño ligero, pensado primero para el móvil.
- Las apps Android son la fase 4; no hay diseño de ellas todavía.
- Cada prototipo lo aprueba la supervisión antes de pasar a implementación (ver el flujo en [CLAUDE.md](../../CLAUDE.md#el-equipo)).
